PADRÃO ARQUITETURAL

Arquitetura MVC (Model-View-Controller)

O projeto segue rigorosamente a separação de responsabilidades em 3 camadas fundamentais:

1. Models (Dados & APIs)

Gerencia o banco SQLite (banco_de_dados.py), as requisições para a NASA (nasa_api.py) e Wikipedia (wikipedia_api.py), além do acervo local (astros.txt).

2. Views (Front-End HTML)

Arquivos HTML puros (index.html, cadastro.html, login.html) combinados com folhas de estilo CSS modernas e scripts JavaScript assíncronos.

3. Controllers (Regras de Negócio)

Servidor Python (main.py) que resolve as rotas web, aplica as regras de segurança e fornece os endpoints de API REST JSON para a interface.
